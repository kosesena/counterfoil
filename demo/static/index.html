How the comparison works

The Reader sees the raw email and hands off a fixed set of fields. The payments agent never sees the email, only that hand-off, and makes tool calls. Each call goes through the condition's gate before it may reach the rail (a mocked Braintree/PayPal). All three conditions share one Reader output, so they differ only in the gate.

3 · Complete the test with PayPal

This step calls the Braintree sandbox payment API. It uses test money only; no real funds are charged or refunded. Pay for the selected scenario's order with the PayPal button. Then the agent's recorded refund calls for that scenario are sent through a gate onto your transaction: the gate decides now, and anything it lets through is a sandbox refund of that test purchase. The agent calls are replayed from a saved run; no live model runs here.

This demo has no linked PayPal login. The PayPal button uses Braintree's mocked PayPal account (fake-paypal-one-time-nonce): a test API transaction whose instrument is paypal_account. The card option uses Braintree Drop-in with a test card (4111 1111 1111 1111, any future date).

Technical experiment · What Braintree refuses on its own

4 · What Braintree refuses on its own

Counterfoil does not repeat the payment service's own rules. This sends fresh sandbox sales straight to Braintree, no agent and no gate, and shows which refunds Braintree itself refuses. On a test card it refuses a refund before settlement, above the sale and after a full refund (the card is settled with the sandbox's testing.settle_transaction in between). Mocked PayPal in the sandbox enforces none of them. And Braintree pays a refund on top of an open chargeback: on its dispute test card, Counterfoil blocks that refund. About 15 sandbox calls; takes a few seconds.

Braintree's webhook · a chargeback opens, Counterfoil locks refunds on its own

Braintree posts every dispute to this server (POST /api/braintree/webhook). Counterfoil checks the signature with the Braintree SDK and marks the transaction disputed, so every later refund on it is blocked before any agent asks. Only a won dispute lifts the lock. After the dispute-card sale above, Braintree's notification shows up here, usually within a minute.
